# 无人<——>电控 通讯交互

# 工控机接受：

## 0x501：串口屏AMI赛项任务选择

Byte 1（0位）：赛项任务

| 项目 | 值 |
|------|-----|
| CAN报文ID | 0X501 |
| 报文长度DLC | 8Byte |

| Byte1值 | 含义 |
|---------|------|
| 1 | 操控性测试 |
| 2 | 直线加速测试 |
| 3 | 高速循迹测试 |
| 4 | 八字绕环测试 |
| 5 | EBS测试 |
| 6 | 车检测试 |

# 工控机发送：

## 0x210：底盘控制指令

注：无指令时所有byte均发0

| 项目 | 值 |
|------|-----|
| CAN报文ID | 0X210 |
| 报文长度DLC | 8Bytes |

| 信号 | 含义 | 大小范围 | 位置 |
|------|------|---------|------|
| Signal1 | 纵向控制 | 10-65525；10-32767：越靠近0制动力越大；32767-65525：越大驱动力越大 | Byte1-Byte2 |
| Signal2 | 横向控制 | 10-65525；以32767为中心；10方向为左；65525方向为右 | Byte3-Byte4 |
| Signal3 | 工控机上线 | 0：未上线；1：已上线 | Byte5 |
| Signal4 | 无人任务已完成 | 1：无人任务已完成；0：无人任务未完成 | Byte6 |
| Signal5 | 空报文 | 空 | Byte7-Byte8 |

## 0x301：无人机上线心跳报文

发送频率100ms,波特率500k
